# 设计系统（港口海图）

> 管理器 UI 的视觉体系与前端契约。改 `src/css/style.css` 或 `src/js/*.js` 的模板标记前请先阅读。窗口/数据流等运行时机制见 `docs/关键机制.md`。

---

## 概念与配色

- 概念「港口海图」：侧栏 = 停泊漂流瓶的港湾（HARBOR），主面板 = 每只瓶子的航行日志（SKIN LOG）。无签名装饰元素，整体保持安静克制。
- 双主题 token 全部集中在 `style.css` 顶部：`:root`（浅色·白日纸面，默认）与 `:root[data-theme="dark"]`（深色·夜航）。组件规则一律引用变量；主题块之外的硬编码颜色只允许：语义色（绿 success / 红 danger）、彩色按钮上的白字与白色开关头。
- **白色为主 + logo 海浪蓝为辅助色**：底色纯白（`--bg-app` / `--bg-surface` = `#ffffff`），侧栏仅用极淡冷灰（`#f3f8fb`）分区；accent = logo 海浪的深水蓝 `#0e75c3`（白底 4.8:1，浅浪端为 `#2da0db`），主按钮渐变 `#1279c4 → #0e68b4` 配白字（两端对比度 ≥ 4.5:1）。白底给了 logo 蓝足够的色相张力——深色藏青底上"蓝配蓝显闷、logo 被自己的颜色淹没"的旧顾虑在白底上不成立。深色块的 accent 仍是 199° 天蓝 `#5fbde8`（取自 logo 上半天空，`#aadffa` 一带压暗）。
- **深色抗疲劳约束（勿回归，仅约束深色块）**：底色不得回到近黑（保持 `#0f1a24` 量级）、正文保持 ~87% 亮度（`#c8dae1`）、accent 不过亮。亮-on-黑的光晕是深色视觉疲劳的根因；当前对比度（正文 ~10:1）仍远超 WCAG AA 4.5:1，不要为了"更精神"往回推。

## 字体契约

- `--font-display`（Bahnschrift，Windows 自带，**不要打包字体**）：只用于拉丁大写眉批、品牌名、面板标题；中文自动落回栈内雅黑。
- `--font-mono`（Cascadia Code）：坐标、版本号、元信息等数据读数。
- 双语节标题标记 = `<h3>中文<span class="sec-en">LATIN</span></h3>`，菱形 `h3::before` 由 CSS 自动添加。**仅内置四节**带拉丁眉批：外观 APPEARANCE / 行为 BEHAVIOR / 位置和大小 GEOMETRY / 操作 ACTIONS；皮肤自定义分组的 `<h3>` 只有中文组名，不加 `sec-en`。
- 配置页页眉的 'SKIN LOG' 眉批是 CSS 生成内容（`.cfg-header-main::before`），改文案在 CSS 里改，不在 JS。

---

## 海图与标绘语言

- 空态（`.panel-empty`）= `--chart-line` 网格背景 + 漂流瓶线稿 SVG + `.drift-wake` 虚线航迹。同款标记存在两处：`app.js` `renderShell()` 与 `skin-editor.js` `clear()`，**改动必须同步**。
- 菱形 = 海图标绘点，是这套 UI 的符号：节标题 `h3::before` 菱形、滑块手柄（`transform: rotate(45deg)`）。新增控件沿用同一符号，不要引入新图形语言。

---

## JS ↔ CSS 契约

- 各渲染函数（`app.js` / `skin-list.js` / `skin-editor.js` / `install-wizard.js` / `settings.js` / `toast.js`）与 `style.css` 之间的契约是**类名**。换肤/改样式不要重命名：`.skin-card`、`.config-section`、`.cfg-*`、`.wizard-*`、`.confirm-*`、`.toast`、`.settings-*`、`.status-badge` 等。
- 主题变量只挂 `:root[data-theme="dark"]`，不能裸写 `[data-theme="dark"]`（原因见 `docs/关键机制.md`「行为约束」）。
- `.win-btn` 的 `:hover` 由 `body.hover-ok` 门控，同理见「行为约束」，换样式时保留门控选择器结构。

---

## 皮肤卡片选中态

- `.skin-card.selected` = 中性描边 + `inset` 左缘 2px 色条 + 外侧 1px 环（`box-shadow`）。
- 描边**不要**染 accent 色：与同色外环相贴，会在左缘 4px 内叠出色条/描边/外环三条平行线（曾出现，已修并截图验证）。

---

## 视觉验证工作流

- UI 改动后用 Edge 无头截图自查：写临时预览页（`<link>` 引用 `src/css/style.css` + 渲染函数同款标记，可用 URL hash 切 `data-theme`），然后：
  ```
  msedge --headless=new --disable-gpu --hide-scrollbars \
    --virtual-time-budget=3000 --window-size=1280,860 \
    --screenshot=out.png "file:///D:/Project/Driftlet/__ui-preview.html#main"
  ```
- `--virtual-time-budget` 必须加——让 fadeUp/popIn 动画播完，否则截到半透明中间帧误判为配色问题。
- 预览页与截图是临时产物，用完即删，不入库。
