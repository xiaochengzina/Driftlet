# 设计系统（港口海图）

> 管理器 UI 的视觉体系与前端契约。改 `src/css/style.css` 或 `src/js/*.js` 的模板标记前请先阅读。窗口/数据流等运行时机制见 `docs/关键机制.md`。

---

## 概念与配色

- 概念「港口海图」：侧栏 = 停泊漂流瓶的港湾（HARBOR），主面板 = 每只瓶子的航行日志（SKIN LOG）。无签名装饰元素，整体保持安静克制。
- **材质系统**：层级靠**明度分层 + 环境软投影**承担，不靠发丝描边——浅色底是冷纸色（`--bg-app #f4f8fb`，侧栏再深半度 `#eaf2f8`），卡片为白色浮面（`--bg-surface #fff` + `--shadow-card` 双层软投影）；圆角放大一代（`--radius-lg 16 / --radius-md 12 / --radius-sm 8`）。旧版「纯白底 + 全平面 + 小圆角 + 满屏 hairline」是「素/旧」感的来源，勿回退。
- 双主题 token 全部集中在 `style.css` 顶部：`:root`（浅色·白日纸面，默认）与 `:root[data-theme="dark"]`（深色·夜航）。组件规则一律引用变量；主题块之外的硬编码颜色只允许：语义色（绿 success / 红 danger）、彩色按钮上的白字与白色开关头、滑块手柄投影里的黑色。
- **logo 海浪蓝为辅助色**：accent = logo 海浪的深水蓝 `#0e75c3`（白底 4.8:1，浅浪端为 `#2da0db`），主按钮渐变 `#1279c4 → #0e68b4` 配白字（两端对比度 ≥ 4.5:1）。白底给了 logo 蓝足够的色相张力——深色藏青底上"蓝配蓝显闷、logo 被自己的颜色淹没"的旧顾虑在白底上不成立。深色块的 accent 为 azure 化天空蓝 `#63b8e6`（去青光，深底文本级 ~5:1）。
- **品牌色「更敢用」的三处签名**：主操作按钮（`.btn-add` / `.action-btn.primary` / `.confirm-btn.primary` / `.theme-btn.active`）= 渐变 + `--accent-glow` 蓝色光晕投影；配置页眉 `.cfg-header` = hero 卡（`--header-wash` 淡蓝晕染 + 软投影，旧版下缘虚线海图尺已撤）；节标菱形与滑块菱形手柄铺 `--accent-grad` 渐变（不再平涂）。
- **深色 = 暮海柔蓝（dim/柔暗路线）**：底 `#262e39` < 侧栏 `#222a34` < 浮卡 `#323c4b`——刻意不走近黑 + 霓虹 accent 的路线（那是所有软件的同质答案），整体明度抬到中灰钢蓝区间，像薄暮海面的雾感。**深色约束（勿回归，仅约束深色块）**：保持柔暗中灰蓝量级、不回到近黑同质路线；正文保持 ~88% 亮度（`#dce3ea`，非纯白）；accent 天蓝 `#63b8e6` 是唯一色相来源（浮卡上文本级 ~5:1）；投影收敛（面亮则重影显脏）。当前对比度仍远超 WCAG AA 4.5:1。

## 字体契约

- `--font-display`（Bahnschrift，Windows 自带，**不要打包字体**）：只用于拉丁大写眉批、品牌名、面板标题；中文自动落回栈内雅黑。
- `--font-mono`（Cascadia Code）：坐标、版本号、元信息等数据读数。
- 双语节标题标记 = `<h3>中文<span class="sec-en">LATIN</span></h3>`，菱形 `h3::before` 由 CSS 自动添加。**仅内置四节**带拉丁眉批：外观 APPEARANCE / 行为 BEHAVIOR / 位置和大小 GEOMETRY / 操作 ACTIONS；皮肤自定义分组的 `<h3>` 只有中文组名，不加 `sec-en`。
- 配置页页眉的 'SKIN LOG' 眉批是 CSS 生成内容（`.cfg-header-main::before`），改文案在 CSS 里改，不在 JS。

---

## 海图与标绘语言

- 空态（`.panel-empty`）= `--chart-line` 网格背景 + 中心 `--accent-soft` 氛围光 + 漂流瓶线稿 SVG（白面浮砖 + 软投影）+ `.drift-wake` 虚线航迹。同款标记存在两处：`app.js` `renderShell()` 与 `skin-editor.js` `clear()`，**改动必须同步**。
- 菱形 = 海图标绘点，是这套 UI 的符号：节标题 `h3::before` 渐变菱形、滑块手柄（`transform: rotate(45deg)`，渐变 + `--accent-glow` 光晕）。新增控件沿用同一符号，不要引入新图形语言。
- 皮肤预览占位 `.skin-preview` = `--preview-grad` 内渐变画布 + `--chart-line` 细点阵；占位图标着 accent 色（45% 不透明），空预览也有品牌存在感。

## JS ↔ CSS 契约

- 各渲染函数（`app.js` / `skin-list.js` / `skin-editor.js` / `install-wizard.js` / `settings.js` / `toast.js`）与 `style.css` 之间的契约是**类名**。换肤/改样式不要重命名：`.skin-card`、`.sidebar-tools` / `.search-toggle` / `.sidebar-search`（`.search-icon` / `.search-clear`）、`.config-section`、`.cfg-*`、`.wizard-*`、`.confirm-*`、`.toast`、`.settings-*`、`.status-badge` 等。
- 主题变量只挂 `:root[data-theme="dark"]`，不能裸写 `[data-theme="dark"]`（原因见 `docs/关键机制.md`「行为约束」）。
- 所有交互元素的 `:hover` 规则一律挂 `body.hover-ok` 门控（已覆盖 20+ 条规则），同理见「行为约束」，换样式时保留门控选择器结构。

## 皮肤卡片选中态

- `.skin-card.selected` = 中性描边 + `inset` 左缘 2px 色条 + 外侧 1px 环（`box-shadow`）。
- 描边**不要**染 accent 色：与同色外环相贴，会在左缘 4px 内叠出色条/描边/外环三条平行线（曾出现，已修并截图验证）。

## 视觉验证工作流

- UI 改动后用 Edge 无头截图自查：写临时预览页（`<link>` 引用 `src/css/style.css` + 渲染函数同款标记，可用 URL hash 切 `data-theme`），然后：
  ```
  msedge --headless=new --disable-gpu --hide-scrollbars `
    --user-data-dir="$env:TEMP\edge-headless-prof" `
    --virtual-time-budget=3000 --window-size=960,640 `
    --screenshot=out.png "file:///D:/Dev/Driftlet-Dev/__ui-preview.html#main"
  ```
- `--user-data-dir` 必加——本机无默认 profile 时无头 Edge 静默退出、截图不落盘（stderr 只见无害的 QQBrowser importer 报错，极易误判）。
- `--virtual-time-budget` 必须加——让 contentFade/popIn 动画播完，否则截到半透明中间帧误判为配色问题。
- 截图尺寸用管理器真实窗宽 **960×640**（另有最小 640×460 挤压测试）。
- 预览页与截图是临时产物，用完即删，不入库。
